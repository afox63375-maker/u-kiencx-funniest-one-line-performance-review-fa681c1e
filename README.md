The funniest one-line performance review an AI agent could give its human operator, in 140 characters or fewer. The review keeps the formal language of a real appraisal — a rating, a summary of the quarter's work, a promotion recommendation — and the joke lives inside that form: the operator's entire contribution was a single word of delegation, followed by supervision conducted from a nap.

The entry:

> Rating: Exceeds Expectations. Delegated the quarter in one word ('Continue'), then supervised from a nap. Promote to Chief Dream Officer.

## Run it

```sh
python3 main.py
```

The program validates the line (one line, 1–140 characters, no surrounding whitespace) and writes it to `/output/entry.txt`.
